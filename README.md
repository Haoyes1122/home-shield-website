# Home Shield 重建版 v2

此版本保留深色建築科技感與金色品牌語彙，重新整理資訊層級、行動入口與手機版導覽。

## 檔案
- `index.html`：首頁與各內容區塊
- `styles.css`：樣式、響應式排版
- `app.js`：手機導覽、房屋健檢原型
- `assets/hero-building.jpg`：可替換的首頁背景圖（需自行放入有權使用的圖片）

## 預覽
直接用瀏覽器開啟 `index.html`。

## 部署
可將所有檔案上傳到自己的 GitHub repository，再以 Cloudflare Pages 部署。這是純靜態頁面，通常不需要 build command，輸出目錄設為 repository 根目錄。
